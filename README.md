## About Me

I'm a Mechatronics and Embedded Systems Engineer with a BEng in Mechatronics Engineering and a First Class MSc in Software Design with AI. My work sits at the intersection of hardware and intelligent software — from low-level firmware and motor control to computer vision pipelines and AI-powered systems.

I've worked across aerospace maintenance, electromechanical engineering, and network optimisation, and I'm currently focused on embedded systems and electronic design roles where I can build things that interact with the physical world.

When I'm not engineering, I'm exploring drone surveillance applications, digging into computer vision research, and working on personal projects that solve real problems.
